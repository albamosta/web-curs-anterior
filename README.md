# Nits de Llegenda

## Descripció

Nits de Llegenda és una pàgina web promocional creada per donar a conèixer un festival de cinema a l'aire lliure celebrat a la vora del riu Segre.

La web presenta la informació principal de l'esdeveniment, incloent-hi les dates de celebració, la programació, les preguntes més freqüents, una galeria d'imatges i la informació necessària per assistir-hi, entre altres.

## Tecnologies utilitzades

- HTML
- CSS
- JavaScript

## Execució local

1. Descarregar o clonar el repositori.
2. Obrir el fitxer `index.html` amb qualsevol navegador web.
